FRUITIOS HISTORY

From a prompt
to a desktop.

FruitiOS started small: a command-driven environment. The project grew into framebuffer graphics, a software cursor, mouse input, layered windows, a Start-style menu, and actual desktop applications.

The goal isn’t to clone an old operating system. It’s to continue the design language from where classic desktop computing left off.
